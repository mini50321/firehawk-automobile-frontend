# Shared

Reusable, presentational building blocks with no knowledge of any specific feature. Anything here may be imported by `features/*` or `core/*`, never the reverse.

- `components/` — dumb/presentational standalone components
- `directives/` — reusable standalone directives
- `pipes/` — reusable standalone pipes
- `models/` — shared TypeScript interfaces/types used across features
- `utils/` — pure helper functions
